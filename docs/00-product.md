# 00 — Продукт

## Что это

Telegram-бот, который скачивает **одно видео с YouTube** и присылает его файлом в чат:
MP4 (H.264/AAC, до 8 вариантов качества) или MP3 (LAME V0). Файлы до 2000 МиБ
уходят через MTProto — лимита 50 МБ у Bot API нет.

Ключевое отличие от конкурентов: **реально Full HD/4K + большие файлы + честный прогресс**.
Рынок downloader-ботов в Telegram переполнен (см. [60-growth.md](60-growth.md)),
поэтому позиционирование строим не на «единственный в нише», а на качестве доставки.

## Границы продукта (это важно, не только для маркетинга)

Продукт — **«личное офлайн-просматривание»**, а не «распространение контента».

| Делаем | Не делаем |
|---|---|
| Отдаём файл конкретному юзеру в личный чат | Публикация/репост в каналы и группы |
| Скачивание по прямой ссылке от юзера | Каталог видео, поиск по всей библиотеке YouTube |
| Личное использование (просмотр офлайн) | Перепродажа, «скачай и выложи» |
| Жалоба/удаление по запросу правообладателя | Отказ от жалоб («напишите правообладателю сами») |

Обоснование: [50-risk-legal.md](50-risk-legal.md) — ToS Telegram прямо запрещают
распространение пиратского контента и чужих медиа без согласия (§5.2 h, i).
Функции «отправить в канал» / «поделиться» в боте **не делаем** — это ровно то,
что переводит сервис из «личного использования» в «распространение».

## Нативный 360p — ключевой технический факт

В YouTube у большинства видео есть **нативные** низкие качества: 144p, 240p, 360p
(format 18/134/230 — mp4/avc1, с аудио). Проверено на трёх роликах — 360p есть везде.

Отсюда следствие: **free-тариф «360p» не требует перекодирования**. Мы просто выбираем
нативный формат. Себестоимость free-трафика ≈ $0.

Перекодирование 1080p60 → 360p стоит **419 CPU-сек на 10-минутный ролик**
(в 70 раз дороже скачивания). Правило: **никогда не кодируем**. Если нативного 360p нет —
отдаём 240p/144p, а не рендерим.

## Каналы продукта

1. **Telegram-бот** — основной. Приватный сейчас, станет публичным.
2. **Сайт** (домен покупаем) — витрина, SEO, точка продажи ЮKassa/крипты, лендинг.
3. **Telegram-канал** — контент-маркетинг, анонсы, промокоды.
4. **YouTube-канал** — туториалы «как скачать в 1080p» (SEO + доверие).

Сайт — не «вторая версия бота», а витрина + юридически чистая точка продажи
(внутри Telegram цифровые товары можно продавать только за Stars — [30-payments.md](30-payments.md)).
