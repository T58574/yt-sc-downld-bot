# 70 — Бренд, нейминг, дизайн

## Нейминг: правила отбора

1. **Не использовать** «download», «downloader», «save» — в поиске Telegram это мусор,
   плюс триггер спам-фильтров.
2. Длина 5–10 символов, читается с одного взгляда, не путается с существующими.
3. Один смысл, без привязки к YouTube (иначе риск «выдаём себя за официальный сервис»
   — ToS §8.1 про брендинг, плюс репутационно).
4. Должно быть занято: ник в Telegram + домен.

## Кандидаты

| Ник | Имя | Комментарий |
|---|---|---|
| **ClipGrab** | ClipGrab | clip + grab: «забрать клип». Короткий, английский, домен .app/.dev реально |
| **Tubely** | Tubely | tube + -ly: мягче, брендово, легко склоняется в русском тексте |
| **VidCatch** | VidCatch | «ловить видео», понятно сразу |
| **PullTube** | PullTube | «тянуть», прямая метафора действия |
| **Snag** | Snag | максимально коротко, но слабее as brand |
| **Тяни** | Тяни | по-русски, если делаем русскоязычный продукт первым |

**Рекомендация: ClipGrab** (запасные: Tubely, VidCatch). Проверить доступность ника
и доменов `.app`/`.dev`/`.bot` перед фиксацией. Домен под сайт — сразу на бренд,
чтобы не потерять репутацию при смене.

## Айдентика (минимальный набор, без дизайнера)

| Элемент | Требование |
|---|---|
| Логотип | play-треугольник + стрелка вниз (или «захват»). Моно-форма, читается в 32px |
| Аватар | 512×512, безопасная зона 40%, контраст с Telegram-синим |
| Палитра | 1 акцент + тёмный фон + светлая тема. Кандидаты: акцент `#FF4D4D` (скачивание/энергия), `#7C5CFF` (фиолетовый, «премиум»), `#22C55E` (зелёный, «готово») |
| Шрифт | системный/Inter — без засечек, читается в мелком |
| Правило | **не использовать логотип YouTube** и зелёный цвет YouTube как основной акцент |

Один Figma-файл с компонентами: `Button / Card / QualityRow / Progress / Paywall /
LimitNotice / Invoice`. Этого хватит, чтобы вся вёрстка бота была единой.

## UI-шаблон бота

```
[превью видео 320px]
Название ролика
Автор · 10:34 · 1080p60 · 256 МиБ

[ Выбрать качество ]   ← если лимит позволяет
[ MP3 ]
[ Отмена ]
```

Экраны, которые надо нарисовать до запуска продаж:

| Экран | Когда | Содержимое |
|---|---|---|
| Start | /start | одно обещание + кнопка «Скачать» + «Тарифы» |
| Card | после ссылки | превью, кнопки качества, цена/лимиты |
| Progress | задача | реальный % из yt-dlp, ETA, кнопка отмены |
| Result | готово | файл + подпись, счётчик «осталось N» |
| **Paywall** | лимит исчерпан | «Осталось 0 из 2. Оформить пакет →» + кнопка Stars |
| **LimitNotice** | 360p-режим | честно: «Бесплатно — до 360p. Полное качество — пакетом» |
| Invoice | оплата | Stars-инвойс с фото продукта (люди любят фото в инвойсе) |
| Error | ошибка | человеческий текст + ссылка на /support |

## Тексты (черновики)

### /start
```
Скачиваю видео с YouTube в полном качестве — до 4K и 2 ГБ.

Пришли ссылку — выберу качество и пришлю файл.
Первые 2 ролика в Full HD бесплатно, дальше 360p.

[ Скачать видео ]   [ Тарифы ]
```

### /terms (кратко, полная версия — на сайте)
```
1. Сервис предоставляет файлы для личного офлайн-просматривания.
2. Пользователь отвечает за наличие прав на видео.
3. Перепродажа, публикация и перепост файлов запрещены.
4. Жалобы правообладателей обрабатываются — пишите /paysupport.
5. Лимиты: [N] в сутки, [N] одновременных задач.
```

### /privacy
```
Храним: ваш Telegram ID, счётчик скачиваний, дату последней оплаты.
Не храним: содержимое видео (удаляется сразу после отправки), переписку.
Удалить всё: /deleteaccount
```

## Что не делаем
- Не делаем «премиум-лук» с золотыми градиентами и анимациями: бот дляutility,
  а не для витрины. Доверие даёт скорость и честный прогресс, а не дизайн.
- Не делаем лендинг на 10 экранов: один экран + кнопка + цены.
