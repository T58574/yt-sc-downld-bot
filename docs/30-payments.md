# 30 — Платежи

Три способа: **Telegram Stars** (внутри Telegram), **ЮKassa** и **крипта** (на сайте).
Внутри Telegram цифровые товары можно продавать **только за Stars** — это прямое
требование ToS (см. ниже). ЮKassa и крипта — на сайте, с выдачей прав в боте.

## Юридическая рамка (Telegram Bot Platform Developer Terms)

| Пункт | Что написано | Что это значит для нас |
|---|---|---|
| §6.2 | «transactions for digital goods and services cannot be processed through third-party payment providers… must be executed exclusively through Telegram Stars» | Внутри Telegram (бот/Mini App) — только Stars. За нарушение: уведомление → исключение из store-версий Telegram → **терминация TPA и аккаунта** |
| §6.2.4 | разработчику — **$0.013 за каждый Star** | Планируем выручку по $0.013/Star, а не по цене для юзера |
| §6.2.4 | «Stars… may not become available for advertising credits or rewards for up to **21 days** after their receipt» | Холд 21 день на вывод |
| §6.2.4.1 | вывод через **Fragment**, в TON (GRAM) | Нужен аккаунт Fragment, доступность по стране |
| §6.2.2 | Stars на балансе — не наша собственность; Telegram может удержать/списать | Риск при возвратах и нарушениях ToS |
| §6.2.6 | включение **topics в личных чатах = 15% от Stars-покупок** | **Не включаем topics** |
| §6.2.7 | Stars живут **3 года**, потом сгорают | Не копим «в запас» дольше 3 лет |
| §6.4 | налоги — наша ответственность | Учитываем в ценах |
| §6.2.1 | обязанность отвечать на `/paysupport` и возвращать Stars | Это в коде, а не «когда-нибудь» |
| §7 | крипто в Mini Apps — **только TON + TON Connect** | Если делаем Mini App с криптой — только TON |

Вывод: **Stars — основной и формально правильный способ.** ЮKassa/крипта — на сайте.

## Telegram Stars — детали

**Создание инвойса:**
```
sendInvoice(chat_id, title, description, payload, provider_token="", currency="XTR",
             prices=[{label, amount}])          # ровно один элемент в prices
```

**Нативная подписка (важно — своя подписка не нужна):**
```
createInvoiceLink(..., currency="XTR", subscription_period=2592000)  # ровно 30 дней
```
- период сейчас только 2592000 с (30 дней), цена подписки ≤ 10 000 ⭐;
- Telegram сам списывает Stars каждые 30 дней, присылает `BotSubscriptionUpdated`;
- отменить/возобновить: `editUserStarSubscription`;
- можно иметь несколько активных подписок одновременно.

**Прочее:**
- `getMyStarBalance` — баланс бота; `getStarTransactions` — история;
- `refundStarPayment` — возврат (штрафа нет);
- `sendPaidMedia` — платные медиа в сообщениях, до 25 000 ⭐ (альтернативная
  модель «плати за каждый файл»);
- paid broadcasts: 0.1 ⭐ за сообщение сверх 30/сек (не нужен).

**Экономика Star'ов.** Юзер платит ~$0.014–0.02 за Star (Fragment — дешевле, в приложении
из-за Apple/Google +30%), мы получаем $0.013. Значит:
- если юзер купил Stars в приложении — мы получаем ~65–90% его уплаты;
- если через Fragment — ~92%.
**Цены надо задавать в ⭐, а не в долларах**, иначе наша маржа «плывёт» вместе с
курсом Star'ов и покупкой внутри приложения.

## ЮKassa

| Параметр | Значение |
|---|---|
| Комиссия с карты | **3.5%** (+ НДС на комиссию) |
| Комиссия СБП | **0–0.7%** (зависит от категории бизнеса) |
| T-Pay / SberPay / ЮMoney | ~3.5–3.8% |
| Самозанятость | налог **4%** (доход от физлиц) / 6% (от юрлиц) |
| Лимит самозанятого | 2.4 млн ₽/год |
| Чеки | обязательны (54-ФЗ), самозанятым — через «Мой налог» |

Итог по карте: ~3.5% + 4% = **~7.5%**; по СБП: 0.7% + 4% = **~4.7%**.
Рабочая схема: **карта (3.5%)** для тех, кто не хочет СБП, **СБП** — основной путь
(дешевле всего).

Нюанс: ЮKassa — провайдер для **физических** товаров по Bot API (с `provider_token`).
Для цифровых — только Stars. Поэтому ЮKassa подключается **на сайте**:
пользователь платит на сайте → сайт выдаёт entitlement → бот видит оплату по `user_id`.

## Крипта

| Вариант | Комиссия | Плюсы | Минусы |
|---|---|---|---|
| **CryptoBot (Crypto Pay API)** | ~0% + сеть ~$0.02 (TON) | официальный API, TON/USDT/BTC, без KYC, мгновенно | сеть только TON в Mini App (ToS §7) |
| Прямой TON-инвойс | 0% | дешевле всего | свой код, свои ключи, риск ошибок |
| Fragment (вывод Stars) | ~5% Fragment + спред TON + биржа | официальный вывод Stars | 21 день холда, TON-курс |

Рекомендация: **CryptoBot** — минимум кода, официальный API, статистика из коробки.
Токен приложения создаётся в @CryptoBot → Crypto Pay → Create App.

## Как устроен единый поток оплаты

```
[Сайт]  ЮKassa / CryptoBot  →  webhook → entitlement(user_id, credits, expires_at)
[Бот]   Stars invoice       →  successful_payment → entitlement(user_id, credits, expires_at)
                                          ↓
                        единый источник прав: таблица entitlements в SQLite
```

Бот **не знает**, какой способ оплаты использовал юзер — он спрашивает entitlement.
Это позволяет менять способы оплаты без изменения кода бота.

## Обязательный функционал (без этого Telegram пришлёт notice, а потом применит санкции)

| Команда | Назначение |
|---|---|
| `/terms` | условия: личное использование, ответственность юзера, запрет перепродажи |
| `/privacy` | какие данные храним и сколько (ToS §4) |
| `/paysupport` | **обязана по ToS** — разбор платёжных споров |
| `/refund` (своя) | ручной возврат Stars через `refundStarPayment` |

## Порядок внедрения

1. **Stars** — в боте. Основной путь, самый простой, без юр. возни.
2. **ЮKassa + CryptoBot** — на сайте, когда появится домен.
3. **Подписка (нативная, Stars)** — когда наберём retention, чтобы было что продлевать.
