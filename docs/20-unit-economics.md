## Формула себестоимости одной обработки

Обработка = скачать + склеить + отдать. Для 1080p, 10 мин, 256 МиБ:

| Статья | Расчёт | $ |
|---|---|---|
| CPU | ~5–6 CPU-сек × $0.00535/vCPU·ч | **0.000009** |
| CPU (если MP3) | ~13 CPU-сек | 0.000019 |
| Трафик | 256 МиБ вниз + 256 МиБ вверх = **0.5 ГБ** | |
| — при безлимитном тарифе | | **0** |
| — при $1/ТБ оверы | 0.5 ГБ × $1/ТБ | **0.0005** |
| Telegram (отправка файлов) | комиссии нет | **0** |
| Диск | временный, 256 МиБ на задачу | 0 |
| **ИТОГО, MP4** | | **$0.00001 – 0.0005** |
| **ИТОГО, MP3** | | **$0.00002 – 0.0005** |

**Себестоимость одной обработки ≈ $0.0005. Себестоимость одного ролика (10 мин, 1080p) ≈ $0.0005.**
Себестоимость часа видео (1.5 ГБ) ≈ $0.003.

Курс для расчётов: 1 EUR = 1.10 USD (плановый).

## Что это значит в деньгах

- Пакет «10 скачиваний» за $4.99 → себестоимость $0.005 → **маржа 99.9%**.
- Порог окупаемости VPS (€7/мес = $7.70) при трафике $1/ТБ: **~15 400 обработок/мес**.
  При безлимитном трафике CPU не окупает вообще ничего — реальный потолок задаёт
  не деньгами, а пропускной способностью Telegram (→ [40-telegram-limits.md](40-telegram-limits.md)).
- **Продавать можно от $0.10 за ролик.** Цену определяет конверсия, не себестоимость.

## Решения, вытекающие из замеров

1. **Не перекодировать никогда.** 419 CPU-сек против 6 — разница в 70 раз. Нативный 360p
   из YouTube бесплатен. Не fallback-ить на перекодирование.
2. **Поднять `UPLOAD_WORKERS` с 4 до 16** (`src/telegram/send-mtproto.ts:8`) —
   доставка ускоряется в 6–7 раз, файл 256 МиБ едет ~20 с вместо ~100 с.
   32 воркера — деградация, не увеличивать.
3. **Не покупать второй VPS на старте.** При 2 vCPU и ~30 с на обработку узкое место —
   не CPU, а канал и лимиты Telegram. Второй VPS нужен, когда упрёмся в трафик/очередь.
4. **Следить за трафиком, а не за CPU.** Трафик = 2 × размер файла на каждое скачивание.
   Счётчик: `2 × Σ размеров` на месяц vs лимит тарифа. ⚠️ **Лимит трафика в тарифе не проверен** —
   уточнить у провайдера (в [90-decisions.md](90-decisions.md) это открытый вопрос).

## Формула для пересчёта при изменениях

```
себестоимость_обработки = CPU_сек/3600 × $/vCPU·ч + 2 × размер_файла_ГБ × $/ГБ_трафика
$/vCPU·ч = (€7 × 1.10 × 12) / (12 × 30 × 24 × 2) = 0.00535
```
